拾い上げの基準と助言の早見表

    
どの回答で項目が立つか、用紙に入る文面、医師向けの対処の要点。CSVがなくても確認できます。

    

  







  

    
使い方

    
    
      
  1. ExChartから PD14（NMSQ）・PD01〜03（MDS-UPDRS）を CSV で出力（「文書日時・患者ID・／項目名」の生出力でも、1行見出しに整えたCSVでも読めます。文字コードは Shift_JIS／UTF-8 を自動判定）。
    2. 
      
  2. 読み込み → 患者IDを入れて「表示」。各票の最新の日付が選ばれ、1つ前の記録と比べます（日付は変えられます）。
    3. 
      
  3. 「アドバイス」タブで、載せる項目を確認して印刷。カルテ用メモはコピーして貼り付け。
    4. 
      
  4. CSVがない時は「症状から」タブで、運動症状・非運動症状をタップすると説明文とイラストが出ます。選んだ症状で同じ用紙を印刷できます。
    5. 
    

    
拾い上げの基準（既定）

    
    
      
  • NMSQ：「はい」の項目。
    • 
      
  • MDS-UPDRS：原則 2（軽度）以上。安全に関わる項目（幻覚 1.2、ドパミン調節異常 1.6、立ちくらみ 1.12、すくみ 2.13・3.11）は 1 以上。
    • 
      
  • 赤（早めの相談）：幻覚で洞察の低下（1.2≧3）、NMSQ 30（妄想）、ドパミン調節異常 1.6≧2、日中の眠気 1.8≧3、嚥下 2.3≧3、立ちくらみ 1.12≧3、姿勢の安定性 3.12≧3 または 歩行とバランス 2.12≧3、抑うつ 1.3≧3。
    • 
      
  • 前回より 1 点以上悪化した項目には「悪化」と付けます。
    • 
    

    
基準と文面は本アプリ独自の目安です（ガイドラインの推奨そのものではありません）。医師向けの薬剤名は一般的な選択肢で、用量・適応は未照合です。処方前に添付文書で確認してください。
