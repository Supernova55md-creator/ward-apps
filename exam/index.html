所見の要約（1行）

神経学的所見（カルテ定型文）

この欄は手で直せます（直した内容は保存されません。診察タブで入力を変えると作り直されます）。電子カルテに貼るときの文字化けを避けるため、記号は半角の - + / と ± だけを使い、Barré などのアクセント記号は外して出力します。

神経病巣局在ナビに送る所見

局在ナビの「所見入力」を、この診察の所見で置き換えます（局在ナビに保存したケースと優位半球の設定は残ります）。麻痺はMMT・Barré・Mingazzini・顔面麻痺から、感覚は感覚の表から、腱反射亢進・低下は腱反射の表から自動で組み立てます。送ったあとは局在ナビ側で追加・修正できます。

使い方

  1. 「診察」タブで上から順に診察し、項目ごとに正常／異常／未施行を入れる。右上の「次の未評価 ↓」で抜けている項目へ飛べます。
  2. 「カルテ」タブで定型文と1行要約をコピーして電子カルテへ貼る。
  3. 局在を考えたいときは「局在」タブから神経病巣局在ナビへ送る。
  4. 次の患者さんの前に、右上の「入力クリア」で消す。

入力はこの端末のブラウザ内にだけ自動保存されます。氏名・ID・生年月日などは入力しないでください。診察所見の判断を置き換えるものではなく、記載の補助ツールです。

表記のきまり

  • 左右のある所見は「所見がある側」で入力（共同偏視は眼が向く側、注視麻痺は向けない側、舌は偏る側、半盲・無視は欠損側）。
  • 腱反射：- 消失、± 低下、+ 正常、++ やや亢進、+++ 亢進、++++ 著明亢進（クローヌス）。
  • MMT：MRC 0〜5（4+・4-を含む）。表の数字は右/左。
  • JCS 0〜300、GCS は E・V・M を別々に（挿管は V=T、失語は V=A）。
